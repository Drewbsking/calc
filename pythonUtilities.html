Edit the marked settings

Every download has a clearly marked settings box near the top. Folder utilities use FOLDER_PATH. For a single input file, the MediaWiki converter uses CSV_FILE_PATH, the wrapped-data cleaner uses INPUT_FILE_PATH, and the PDF-to-MP3 converter uses PDF_FILE_PATH. Some scripts also need a marker, suffix, number range, or other job setting.

# FOLDER_PATH: paste the folder you want to process.
FOLDER_PATH = r"C:\CHANGE_ME\YourFolder"

For example, use FOLDER_PATH = r"C:\Work\Turning Prohibitions". Keep the r and quotation marks. Spaces are fine; do not put a backslash at the end of the path.

  1. Check Python. Open Windows Terminal and enter py --version. If Python is missing, follow the official Python Windows setup instructions. Only the PDF-to-MP3 converter needs extra packages; its listing includes the install command.
  2. Find your folder path. In File Explorer, open the folder you want to process, click the address bar, and copy the full path. Paste it between the quotes in the script. Any mapped drive must be connected when the script runs.
  3. Review that utility's settings. Each listing identifies its file types and whether it includes subfolders. The third-section replacement and year conversion require you to supply the historical job settings before they will run.
  4. Edit and save the download. Use Notepad or another text editor. If using Save As, choose All files and keep the .py extension, rather than .py.txt.

When you run a script: file-changing utilities apply their operation immediately, except Find and Replace, which previews changes and asks for confirmation. Report tools only print findings. The MediaWiki converter, wrapped-data cleaner, and PDF-to-MP3 converter create new output files and leave their inputs unchanged. Subfolder behavior is shown on each listing. Existing files are not overwritten, and symbolic links are not processed. The website does not receive your files. The PDF-to-MP3 script sends extracted text to Google's speech service and requires internet access; the other utilities work locally.

Convert a Pay-Item CSV to MediaWiki

Turn a pay-item CSV export into a MediaWiki table ready to paste into a wiki page's source editor. The table columns are PayItemCode, Units, Description, and AUP, in that order.

CSV input
PayItemCode,Units,Description,AUP
0012345,Ea,"Example, item",12.50
MediaWiki output
{| class="wikitable"
! PayItemCode !! Units !! Description !! AUP
|-
| 0012345 || Ea || Example, item || 12.50
|}

The CSV must include those four headers; their order can vary, and extra columns are ignored. Quoted commas, blank cells, UTF-8 text, and line breaks in cells are supported. Item codes keep leading zeros and values keep their original decimal formatting. Literal wiki characters are escaped. The default output is MediaWiki_Table.txt beside the CSV; choose another output path if that file already exists.

Use this for data where every record starts on a line containing a comma and continuation lines contain no commas. Any comma, including one inside quotes, starts a new record. Outer whitespace is trimmed, blank lines are ignored, and existing text and numeric formatting are preserved. This operation does not validate CSV columns or quoted multiline fields.

The default output is <input name>_cleaned.csv beside the input. The source is unchanged, and existing output files are never replaced. If nonblank text appears before the first comma-containing record, the script reports the line number without creating output.

If something needs attention

“Set FOLDER_PATH” or “Folder not found”
Replace the example path, save the script, and check that the folder exists and any network drive is connected.
A job setting is missing
Review the listing's settings. The historical third-section and year rules deliberately start incomplete because their old values may not fit your records.
“Permission denied” or a file is in use
Close the file in other apps and check that you can edit files in that folder. The script reports the problem and continues with other files.
“Destination already exists”
The operation was skipped for that file. For example, if both Meeting Notes.docx and Meeting-Notes.docx exist, neither is overwritten.
Python cannot open the script
Open the terminal in the folder containing the downloaded script and check that its filename ends in .py.
The py command is not recognized
If Python is installed, try python in place of py. Otherwise, use the setup link above.
The summary says 0 changed
Check the settings, folder, supported file types, and example naming pattern. A file may already match the desired result. Skipped counts also include other file types and excluded entries.
