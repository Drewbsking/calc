How to use
  • Study name / road: enter the road being studied. The name appears on every report page and in the PDF filename.
  • Draw Alignment: click the start, then each tangent endpoint.
  • Add Curve: the last alignment point becomes PC, the end of the tangent. Click MID on the curve first, then PT. Place the alignment start before adding a curve.
  • After PT, click ahead along the red guide to extend the tangent, or select Add Curve again.
  • Drag PC or PT to adjust the curve along its tangents; drag MID to change the radius. Moving PC on a straight between two curves rotates that straight and refits both curves to keep smooth connections.
  • Dragging a straight-section endpoint changes that line and refits its adjoining curves. Edits that cannot fit keep the last valid shape.
  • Draw Alignment cancels an unfinished curve. Finish ends drawing; either drawing button resumes it.
  • Stations appear every 500 ft. On touch screens, finish drawing, then tap near the alignment to read a station.
  • Add Access Points: click a driveway or road access. Press R for Residential, C for Commercial, or N for Named Road / Access. Enter a name for named accesses.
  • Save (Enter) or click the next location to keep adding; the last type is reused. Points and edits are kept as you enter them. Use Delete to remove a point.
  • Residential markers are green circles, Commercial markers are orange squares, and named accesses are purple diamonds. Click a table row to locate and edit a point. Drag its marker to move it.
  • Access stations update when points or the alignment move. Reset clears both the alignment and access points.
  • Reports: print or save a PDF with access-based speed recommendations and MCL references. Charts default to 1,000-ft intervals; speed analysis uses sliding 2,640-ft windows. Matching road names within 100 ft share one label; each access still counts separately.
  • Pinch to zoom, or use Shift+drag on desktop for box zoom.

Lengths follow the traced centerline, including circular arc lengths. Measurements are map-derived.

Reports

Every PDF includes the study map, MCL speed recommendation, and a separate hypothetical graph using each 100-ft section's density. Print and PDF include all pages of the selected report.
