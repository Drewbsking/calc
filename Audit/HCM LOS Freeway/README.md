# HCM reference folder

This folder has been integrated and audited. Open the [Basic Freeway LOS calculator](../../freewayLOS.html) from the toolbox. See the [audit report](../../docs/hcm-audit.md) for source mapping, corrections and the independently recalculated example.

`LOS.py` is the original archived script and contains known calculation errors. The site uses the corrected browser implementation. The five supplied source files have been preserved unchanged.

`LOS - Freeway.pdf` is HCM Version 6.0. The separate HCM7 reference guide supports review; its presence does not make the calculation a verified 7th Edition implementation.
